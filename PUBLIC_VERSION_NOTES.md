# Code-only public release notes

This package intentionally excludes `TetrisBattle/assets/original_visuals/` and `TetrisBattle/assets/tetris sounds/sfx_packs/original_facebook/` because the extracted Flash game media do not have a clearly documented public redistribution license.

Original-style sound/graphics features may fall back to existing assets. The README demonstration GIFs are newly rendered from the Python board model and do not include original Flash media.

Earlier validation of this code-only package reported 119 tests passing and 21 optional media-dependent tests skipped. This is historical evidence, not a new claim of GUI or Windows hardware testing.

**Important:** Some upstream-provided art/music may still require separate rights review before public release. The MIT code license does not automatically cover third-party media. See `NOTICE.md`.
